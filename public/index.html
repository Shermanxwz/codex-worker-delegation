保护边界
✓ 密码使用 scrypt hash 保存，不保存明文✓ HttpOnly / SameSite 会话，登录失败限速✓ loopback 默认只允许本机；公网必须使用 HTTPS、CWD_REQUIRE_AUTH=1 和反向代理✓ 控制面密码与 New API Key、ChatGPT OAuth 完全分离

第三方密钥写入本项目加密 vault。Codex 只获得本地 gateway token，不会读取或替换 ChatGPT 的 auth.json。

          

          
模型会出现在哪里？
New API 模型会出现在本控制面的路由和连通性列表中，并通过 codex_worker_gateway 的隔离线程执行。原生 Codex 的自定义 provider 目录也提供兼容格式；但它仍是独立 provider，不能混进官方 openai 模型下拉框。这样才能保留官方 provider 与登录状态不变。
